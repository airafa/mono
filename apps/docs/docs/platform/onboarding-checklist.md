# Platform Onboarding Checklist

## Purpose

Track the onboarding steps needed to make platform capabilities available for this repository across environments.

## Pre-Onboarding Requirements

- [ ] Platform owner identified for each capability
- [ ] Repository registered with platform team
- [ ] Access credentials provisioned for product team members

## CI/CD Onboarding

- [ ] Pipeline configuration created
- [ ] Build agents assigned
- [ ] Branch protection rules configured
- [ ] Deployment triggers defined per environment
- [ ] Build caching configured

## Artifact Management

- [ ] Package registry access granted
- [ ] Artifact naming conventions agreed
- [ ] Retention policies configured
- [ ] Build output publishing configured

## Secrets Management

- [ ] Secrets vault access provisioned
- [ ] API key rotation policy defined
- [ ] Environment-specific secret scopes created
- [ ] Local development secret access configured

## Observability

- [ ] Application logging pipeline configured
- [ ] Metrics collection enabled
- [ ] Distributed tracing enabled
- [ ] Dashboard templates created
- [ ] Alert routing configured

## Hosting

- [ ] Dev/Integration environment provisioned
- [ ] Staging environment provisioned
- [ ] Production environment provisioned
- [ ] DNS and routing configured
- [ ] TLS certificates provisioned

## Networking and Access

- [ ] Network policies applied per environment
- [ ] Access control lists configured
- [ ] Backend service connectivity verified
- [ ] Firewall rules reviewed

## Compliance

- [ ] Compliance owner named
- [ ] Applicable controls documented
- [ ] Release approval workflow configured
- [ ] Audit evidence requirements defined
